## Selected Projects

&nbsp;

**AI Finance Intelligence System**
`Python · FastAPI · Scikit-learn · JavaScript · Chart.js`

An intelligent personal finance system that forecasts expense trends and surfaces behavioral spending insights through predictive analytics.

```
What I explored:
  - Training regression models on personal transaction sequences
  - Designing adaptive budget thresholds with real-time alert logic
  - Layering interactive Chart.js visualizations over ML predictions
  - Building a proactive nudge system for financial habit formation

Observation: Spending velocity trends (acceleration/deceleration)
proved more actionable than raw totals for behavioral change.
```

→ [github.com/KarunyaKalk/AI-Finance-Tracker](https://github.com/KarunyaKalk/AI-Finance-Tracker)

&nbsp;

**Metro Rail AI Scheduling System**
`React.js · Node.js · Predictive Algorithms · Optimization`

AI-based scheduling system for Kochi Metro Rail Limited — optimizing train induction and timing using dynamic ridership forecasting.

```
What I explored:
  - Demand-aware induction scheduling with predictive load modeling
  - Real-time visualization of scheduling decisions for operators
  - Balancing resource utilization efficiency against service frequency

Observation: Scheduling constraints are deeply interdependent —
small changes in headways ripple into resource availability upstream.
```

**GreenPulsePortal** *(Hackathon Project)*
`React.js · Node.js · MongoDB · REST APIs`

A sustainability platform with carpooling coordination, meal donation logistics, and a green marketplace — built to reduce friction in eco-friendly decision-making.

```
What I explored:
  - Designing multi-module systems with a shared user identity
    and notification layer across distinct feature areas
  - Integrating analytics to surface community engagement patterns

Observation: Behavioral products need low-resistance entry points —
friction in the first action kills the habit loop entirely.
```
